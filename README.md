# pi-vipi-themes

48 light and dark themes for the Pi coding agent: Catppuccin, Everforest, Flexoki, Gruvbox, Kanagawa, Rosé Pine, Tokyo Night, Nord, and more.

## Install

```sh
pi install git:github.com/vimhead/pi-vipi-themes
```

Run **`/reload`**, then choose a theme in **`/settings` → Theme**. Pi saves your selection.

[Browse all themes](themes). For one session, use a name such as `pi --use-theme flexoki-dark`.

Enabled by default in [Vipi](https://github.com/vimhead/vipi). To disable, select a built-in theme first, then turn this package off in `/vipi` and sync, or run `pi remove git:github.com/vimhead/pi-vipi-themes`.
